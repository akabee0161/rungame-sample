# Space Runner — ゲーム設計仕様書

**日付**: 2026-06-03  
**対象**: 5〜8歳の幼児  
**プラットフォーム**: スマートフォン（横向き）＋ デスクトップブラウザ

---

## 1. ゲーム概要

宇宙をテーマにしたエンドレスランナー。プレイヤーは自動で右へ走り続け、障害物を避けながら生き延びた時間でスコアを競う。ダブルジャンプのみの極シンプルな操作で、幼児でも直感的に遊べる。

---

## 2. 操作

| アクション | 入力 |
|---|---|
| ジャンプ（1回目） | 画面タップ / スペースキー |
| ダブルジャンプ（2回目） | 空中でもう一度タップ / スペースキー |

- 地面接地後に再びタップ/スペースで1回目のジャンプに戻る
- スライドなし

---

## 3. 画面・向き

- **解像度**: 720×405px（16:9 横向き）
- **向き制御**: タイトル画面のタップ時に `screen.orientation.lock('landscape')` を呼び出す
- **フォールバック**: API非対応ブラウザでは「端末を横向きにしてください」メッセージを画面内に表示
- **デスクトップ**: 向きロックAPIは無視し、そのままプレイ可能

---

## 4. シーン構成

```
Boot → Preload → Title → Game → GameOver
                  ↑                  |
                  └──────────────────┘ (リトライ)
```

### 4.1 Boot
- Phaser の設定初期化のみ。次の Preload へ即遷移。

### 4.2 Preload
- アセットの読み込み（Graphics API で生成するため最小限）
- ローディングバー表示

### 4.3 Title（新規）
- ゲームタイトル「🚀 SPACE RUNNER」を大きく表示
- 「タップしてスタート」の点滅テキスト
- タップ/クリック時に `screen.orientation.lock('landscape')` を呼び出してからゲームシーンへ遷移

### 4.4 Game（拡張）
- メインゲームプレイ
- HUD: 左上にスコア（大きめフォント）
- 地面: 画面下部に固定ライン
- 背景: 星のパーティクルが右から左へ流れる（視差スクロール）

### 4.5 GameOver（新規）
- 「GAME OVER」テキスト
- 最終スコア表示
- 「もういちど！」ボタン（タップでタイトルへ戻る）

---

## 5. スコアシステム

| 要素 | 点数 |
|---|---|
| 生存時間 | 1秒ごとに +10点 |
| 星コイン取得 | 1個につき +50点 |

- スコアはゲーム中リアルタイム更新
- ハイスコアはローカルストレージに保存（GameOverとTitleに表示）

---

## 6. 障害物・アイテム

| 種類 | 形状 | 高さ | 幼児向け色 |
|---|---|---|---|
| 隕石 ☄️ | 丸い岩 | 低い（1回ジャンプで越えられる） | オレンジ〜茶色 |
| UFO 🛸 | 楕円形 | 中くらい（ダブルジャンプが確実） | 明るい緑 |
| 宇宙人 👾 | 丸い頭＋目 | 低い（1回ジャンプで越えられる） | 明るい紫 |
| 星コイン ⭐ | 星形 | ランダム高さ | 黄色 |

- すべての障害物は **地面から出現し、ジャンプで飛び越える** 統一メカニクス（「ジャンプしてはいけない障害物」は存在しない）
- 各フレームで右端から出現し、左へ一定速度で移動
- 連続して出現する場合は必ずジャンプで回避できる間隔を保証する

---

## 7. 難易度システム

- **スクロール速度**: 固定（変化しない）
- **障害物出現間隔**: ゲーム開始時は 2.5秒、20秒ごとに 0.25秒短縮（最小 0.8秒）

| 経過時間 | 出現間隔 |
|---|---|
| 0〜19秒 | 2.5秒 |
| 20〜39秒 | 2.25秒 |
| 40〜59秒 | 2.0秒 |
| 60〜79秒 | 1.75秒 |
| 80秒〜 | … |
| 最小 | 0.8秒 |

---

## 8. ビジュアルスタイル

- **テーマ**: 宇宙（深い紺〜黒の背景）
- **カラーパレット**: カラフルでポップ（黄・ピンク・水色・緑）
- **キャラクター**: 宇宙服を着た丸い人物（Graphics APIで描画）
- **アセット方針**: すべて Phaser の Graphics/Text API で描画。外部画像ファイルなし。後から PNG に差し替えられる構造にする。
